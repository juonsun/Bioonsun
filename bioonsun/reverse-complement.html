Reverse Complement 계산기

DNA·RNA 서열을 붙여넣으면 역상보 서열을 즉시 계산합니다. IUPAC 모호성 코드와 FASTA 형식, 대소문자를 모두 그대로 유지합니다.

Reverse Complement(역상보 서열)란 무엇인가요?

DNA는 두 가닥이 서로 반대 방향(antiparallel)으로 결합한 이중나선 구조입니다. 한쪽 가닥의 서열을 알고 있을 때, 반대쪽 가닥을 5'→3' 방향으로 표기한 서열이 바로 역상보 서열(Reverse Complement)입니다. 계산 방법은 두 단계로 나뉩니다.

  1. Reverse(뒤집기): 서열의 순서를 끝에서부터 거꾸로 읽습니다.
  2. Complement(상보화): 각 염기를 짝이 되는 염기로 치환합니다 (A↔T, C↔G, RNA의 U는 A와 짝).

예를 들어 5'-ATGC-3'의 역상보 서열은 5'-GCAT-3'입니다. 이 도구는 위 두 단계를 한 번에 처리하며, 필요하다면 Reverse만 또는 Complement만 따로 볼 수도 있습니다.

어떤 경우에 사용하나요?

  • PCR 프라이머를 설계할 때 역방향(reverse) 프라이머 서열을 확인할 때
  • 클로닝, 제한효소 자리 확인 등에서 반대쪽 가닥의 서열이 필요할 때
  • 서열 정렬(alignment) 전, 두 서열의 방향을 맞출 때
  • 수업 과제나 실습에서 역상보 서열 개념을 확인할 때

FASTA 형식 지원

>로 시작하는 FASTA 헤더가 포함된 입력을 붙여넣으면, 헤더는 그대로 유지하고 서열 부분만 역상보로 변환한 뒤 60자 단위로 줄바꿈해 정리된 FASTA를 출력합니다. 여러 개의 서열(멀티 FASTA)도 각각 개별적으로 처리됩니다.

사용 방법

  1. 위 입력창에 DNA/RNA 서열(또는 FASTA 형식)을 붙여넣습니다.
  2. 필요하다면 상단 탭에서 Reverse만 / Complement만 / Reverse Complement 중 원하는 모드를 선택합니다.
  3. 결과창에서 바로 복사하거나, FASTA 파일로 다운로드합니다.

자주 묻는 질문

Reverse와 Complement의 차이는 무엇인가요?

Reverse는 서열 순서만 거꾸로 뒤집는 것이고, Complement는 순서는 그대로 두고 각 염기만 상보 염기로 바꾸는 것입니다. Reverse Complement는 이 둘을 모두 적용한 결과입니다.

RNA 서열(U 포함)도 입력할 수 있나요?

네. U는 T와 동일하게 취급되어 A와 상보 관계를 이룹니다. 결과는 DNA 표기(A/T/G/C)로 출력됩니다.

공백, 줄바꿈, 숫자가 섞여 있어도 되나요?

인식되지 않는 문자(공백, 숫자, 기호 등)는 상보 변환 없이 그대로 유지됩니다. FASTA 헤더가 없는 일반 텍스트의 경우 전체 문자열을 기준으로 뒤집기가 적용됩니다.

입력한 서열이 저장되거나 외부로 전송되나요?

아니요. 이 도구는 서버 요청 없이 브라우저(JavaScript)에서만 계산하며, 어떤 서열 데이터도 BioOnSun 서버에 전송되거나 저장되지 않습니다.

결과 줄바꿈 폭(60자)을 바꿀 수 있나요?

현재 버전은 표준 FASTA 관례에 따라 60자 단위로 줄바꿈합니다. 다른 폭이 필요하시면 문의 페이지를 통해 요청해주세요.
