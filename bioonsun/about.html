BioOnSun 소개

작은 불편을 해결하는 생물정보학 도구를 만듭니다.

BioOnSun은 어떤 사이트인가요?

BioOnSun(juonsun.com/bioonsun)은 DNA·RNA 서열을 다루는 연구자, 학생, 취미 생물학자를 위해 만들어진 무료 온라인 생물정보학 도구 모음입니다. 회원가입이나 설치 없이, 브라우저에서 바로 필요한 계산을 할 수 있도록 하는 것을 목표로 합니다.

왜 만들었나요?

실험을 준비하거나 과제를 하다 보면 서열을 뒤집고 상보 서열로 바꾸는 것처럼 사소하지만 반복적인 작업을 자주 하게 됩니다. 기존의 여러 도구들은 광고가 지나치게 많거나, 오래된 인터페이스로 모바일에서 사용하기 불편하거나, 불필요한 회원가입을 요구하는 경우가 많았습니다. BioOnSun은 이런 작은 불편함을 하나씩 해결하는 개인 프로젝트로 시작했습니다.

운영 원칙

  • 프라이버시 우선: 서열 계산은 서버가 아니라 여러분의 브라우저(JavaScript)에서 직접 처리됩니다. 입력한 서열은 BioOnSun 서버로 전송되거나 저장되지 않습니다.
  • 무료 · 광고 최소화: 핵심 기능은 항상 무료로 제공하며, 사용 경험을 해치지 않는 선에서만 광고를 배치합니다.
  • 정확성: IUPAC 표준 코드 등 공인된 생물정보학 규약을 기준으로 계산 로직을 검증합니다.
  • 지속적인 확장: Reverse Complement 계산기, GC 함량 계산기, DNA→단백질 번역기, FASTA 정리 도구, 서열 정렬 비교 도구에 이어, 사용자 의견을 바탕으로 실무에서 자주 쓰이는 도구를 계속 추가할 예정입니다.
