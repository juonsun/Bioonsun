여기서 작성한 글은 서버에 저장되지 않습니다. 아래에서 "zip 생성"을 누르면 완성된 페이지 파일들을 다운로드하고, 그 파일을 로컬 저장소에 넣어 git push 해야 실제로 게시됩니다.

알아두세요. 이 도구는 서버·DB 없는 정적 사이트 구조를 유지하기 위해 "브라우저에서 작성 → 파일 생성 → git push" 방식으로 동작합니다. 진짜 로그인 보안이 아니므로, 이 페이지의 URL은 절대 공개하거나 사이트 메뉴에 노출하지 마세요. 비밀번호를 바꾸려면 assets/js/blog-admin.js 안의 ADMIN_PASSWORD_HASH 값을, 브라우저 개발자 콘솔에서 아래 코드로 새로 만든 해시로 교체하세요:
crypto.subtle.digest('SHA-256',new TextEncoder().encode('새비밀번호')).then(b=>console.log([...new Uint8Array(b)].map(x=>x.toString(16).padStart(2,'0')).join('')))
본문 작성 문법 (마크다운) — # 제목, **굵게**, - 목록, 1. 번호목록, `코드`, 표(GFM) 지원.
실무자 팁 박스: > TIP: 내용 · 결과 해석 박스: > NOTE: 내용 (블록인용문 맨 앞에 TIP: 또는 NOTE: 를 쓰면 자동으로 스타일 박스가 됩니다.)
